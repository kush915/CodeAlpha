# CodeAlpha_PhishingAwareness

Interactive phishing awareness module (single HTML file, no install needed).

## Contents
1. What phishing is
2. 8 types (email, spear, whaling/BEC, smishing, vishing, quishing, clone sites, social)
3. Interactive "spot the phishing email" exercise (6 clickable red flags)
4. Fake URL / domain tricks
5. Social engineering psychology (urgency, authority, fear, greed...)
6. Real cases (RSA 2011, fake-invoice fraud, 2016 email compromise, Twitter 2020 vishing)
7. Best practices + what to do if you clicked (India: cybercrime.gov.in, 1930)
8. 8-question scored quiz with explanations

## Run
Open `index.html` in any browser
